# Jev-like decision seam: isolated J1/J2 control

This is a **non-production, rules-only experiment** on the V5 reset branch. It deliberately imports no archived kernel, model provider, database, Theia plugin, or workflow coordinator. A state compiler whitelists exact historical refs, representation/selector digests, bounded metadata, and semantic closure. Typed `DecisionObservation` carries no operation granting acceptance, execution, egress, or citation verification. Rules abstain on unsupported classifications; partial context and unauthorized local-only egress bypass the adapter. A proposed model must satisfy the same exact option schema and cannot add `accept`.

Run `node --test experiments/jev-seam/*.spec.mjs` on Node >=22 (CI selects 24). Synthetic snapshots cover 2 transcripts, an imported table, 2 codebook editions, overlapping annotations, competing claims, a derived artifact, two snapshots and a corrected source. `j1.json` contains six preregistered synthetic labels; the rules-only control matches 5/6 and abstains 2/6 **by construction**. These are test fixture assertions, **not** empirical J1/J2 qualification, model calibration, durable N2/N6 proof, research accuracy or a V5 architectural choice.

Limitations: no actual Jev/model adapter, no independent annotator, no changed-converter exercise, no CAS/SQL, no observed runtime or egress, no Theia parity. J1/J2 remain open in `docs/reset/experiment-plan.md` until an independently retained controlled run and full N1 composition. This seam is intentionally disposable after the four-way architecture decision.
