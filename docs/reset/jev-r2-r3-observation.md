## Actual experiment

The isolated experiments/jev-seam/semantic.mjs is a removable exact-source/fragment/statement/EvidenceLink context compiler. It checks supplied source byte digest, each record's revision preimage digest, snapshot member manifest digest, exact ref membership, cited selector offsets, representation digests, legal roles and statement/link association. It retains quote plus bounded surrounding context instead of transmitting a whole source. The evaluator refuses incomplete basis or unauthorized egress, restricts outputs to support/partial/unsupported/contradicted/abstain, and grants no acceptance, citation, execution, or publication authority.

The new semantic.spec.mjs contains 14 synthetic adversarial tests alongside the eight earlier metadata-triage tests. Named archive-and-boundaries job in GitHub Actions run 35940270583 passed: 335 archived blobs verified; 22/22 synthetic tests passed. See https://github.com/mberrys/ivory/actions/runs/35940270583 . The independent clean upstream Theia baseline build has a separate conclusion and is not an integrated Core build.

These tests exercise A/B historical ref preservation after synthetic source/claim correction; mechanical quote and representation mismatch; forged/latest/foreign/dangling revision; full-text omission; local-only and approved-body egress boundaries; quote-window minimization; injected action field; malformed distributions; adapter replacement and offline abstention. A scripted provider double with mode "live" is NOT a live Jev observation.

The earlier J1 synthetic rules fixture still matches five of six deliberately authored labels, abstaining in two. This is not model accuracy or meaningful probability calibration. A scripted model can label an irrelevant mechanically exact quote "supported" but cannot create a researcher acceptance receipt; this proves interface separation, not sound semantic classification.

Initial synthetic context creation accepted copied revision-digest strings. That was corrected before recording this observation: each supplied record preimage and snapshot membership are hashed and verified. This remains fixture integrity; only an actual V5 Core can authenticate the underlying admitted historical research state.
